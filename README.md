## Generative Matching Units

The 'Code' folder contains the files for training GMUs, RBFs and MLPs on all the datasets, including CIFAR-10, SVHN, MNIST, F-MNIST and NORB. 

Saved network configurations for each dataset is also provided for all respective networks. 

The 'Demo' folder contains a digit classification demonstration. Instructions for the demo are as follows:

- Put the figure in to_predict_fmnist.png (if running predict_fmnist.py) or to_predict_mnist.png (if running predict_mnist.py). Please crop the figure accordingly and save.
- Run predict_fmnist/mnist.py and click 'Update'. The inferences for CNN, CNN-I (Inverted image presented to CNN) and GMU-CNN is displayed in the top
